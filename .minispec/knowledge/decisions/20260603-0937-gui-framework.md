## Decision

Use **Tauri** (Rust shell + TypeScript/React web frontend + Python sidecar) as the GUI framework.

## Context

The PII anonymization model is Python-based (HuggingFace transformers). The GUI needs to run on both Windows and macOS with a modern look. Three options were evaluated: PyQt6 (pure Python), Tauri, and Electron.

## Choice

Tauri — lightest binary, web-based UI for flexible visualization.

## Trade-offs

- ✅ Very small binary compared to Electron
- ✅ Web UI enables rich text highlighting and flexible layout
- ✅ Rust shell is memory-safe and fast
- ❌ Three languages (Rust + TypeScript + Python) — more moving parts
- ❌ IPC required between TypeScript frontend and Python sidecar

## Consequences

- Python sidecar handles all model inference and file processing
- Frontend communicates via Tauri commands (invoke) over IPC
- UI built with React (or similar) in TypeScript
