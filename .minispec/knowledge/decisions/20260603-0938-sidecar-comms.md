## Decision

Use **stdin/stdout JSON-RPC** for communication between the Tauri shell and the Python sidecar.

## Context

The Python sidecar handles all model inference and file parsing. Tauri needs to send requests and receive results. Two options: local HTTP (FastAPI on localhost) or Tauri's native stdin/stdout sidecar pattern.

## Choice

Stdin/stdout — Tauri's native sidecar support. No local port required.

## Trade-offs

- ✅ No network port to manage or conflict with
- ✅ Aligns with Tauri's intended sidecar model
- ✅ Process lifecycle is managed by Tauri automatically
- ❌ Slightly harder to debug than HTTP (no curl/Postman)

## Consequences

- Python sidecar reads JSON from stdin line-by-line, writes JSON responses to stdout
- Protocol: `{ "id": N, "method": "...", "params": {...} }` / `{ "id": N, "result": {...} }`
- Errors returned as `{ "id": N, "error": { "code": N, "message": "..." } }`
