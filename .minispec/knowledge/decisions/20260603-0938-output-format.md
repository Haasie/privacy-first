## Decision

Use **typed labels** for redacted spans in both the output file and the GUI preview.

## Context

The `openai/privacy-filter` tool supports two native output modes: `typed` (e.g. `[private_person]`, `[private_email]`) and `redacted` (collapses everything to `[redacted]`).

## Choice

Typed labels — the model's native `--output-mode typed` format.

## Consequences

- Output files preserve semantic meaning: readers know what type of PII was removed
- **Actual placeholder format used is `<PRIVATE_PERSON>`, `<PRIVATE_EMAIL>`, etc.** — OPF's native uppercase angle-bracket format. The design doc originally said `[private_person]` but OPF's native format was accepted during Task 5 implementation to avoid post-processing.
- GUI preview colors each label by category (the `label` field from spans, not the placeholder text)
- The PII panel shows `TYPE: original value` pairs
- Typed mode is the default; a settings toggle to switch to generic `[redacted]` is deferred to v2
