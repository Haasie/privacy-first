## Decision

Use **Mantine** as the React UI component library for the frontend.

## Context

The frontend needs a cross-platform UI library for the Tauri app. Options considered: shadcn/ui, Mantine, bare Tailwind.

## Choice

Mantine — full-featured React component library with built-in components for progress bars, scrollable lists, file inputs, and tooltips. Covers most of what the privacy-first GUI needs out of the box.

## Consequences

- Add `@mantine/core` and `@mantine/hooks` to frontend dependencies
- Use Mantine's `Progress`, `ScrollArea`, `Tooltip`, `FileInput`, `Textarea`, `Button` components throughout Tasks 9-11
- Theming via Mantine's `MantineProvider`
