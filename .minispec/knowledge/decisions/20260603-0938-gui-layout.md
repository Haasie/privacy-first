## Decision

Three-area layout: input area (top-left), redacted preview (top-right), PII list panel (bottom full-width).

## Context

The user needs to: provide input, see the redacted result, and inspect what was removed. These are three distinct information areas.

## Choice

- **Input area**: File picker + drag & drop zone + text paste field; output location selector; Process button
- **Preview panel**: Redacted text with color-coded in-place labels per PII category
- **PII panel**: Scrollable list of `TYPE: original value` entries; Copy and Save buttons

## Consequences

- Preview shows replaced text (not original with overlay) — simpler to implement, sufficient for v1
- Color coding requires a stable color-per-category mapping (8 categories = 8 colors)
- PII panel doubles as an audit log of what was redacted
